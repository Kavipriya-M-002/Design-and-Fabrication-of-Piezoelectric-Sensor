# Design and Fabrication of Piezoelectric Sensor

## 🔍 Overview
This project focuses on designing and fabricating a flexible piezoelectric sensor using PVDF and Graphene materials. The sensor was studied through simulations and practical experiments to understand its electrical response and suitability for wearable applications.

## 🛠️ Tools & Technology Stack

| Category | Tools / Technologies |
|---|---|
| Simulation | COMSOL Multiphysics |
| Materials | PVDF, Graphene, PZT-4 |
| Sensor Fabrication | Textile Coating |
| Data Collection | Arduino UNO, Oscilloscope |
| Testing | Conductivity, Loading and Washing Tests |

## ⚙️ Methodology
- Simulated different material combinations using COMSOL Multiphysics.
- Fabricated flexible sensor samples using a textile-based coating method.
- Studied how Graphene coating layers affected conductivity.
- Tested the sensor under different loading conditions.
- Examined the sensor's performance after washing tests.

## 📊 Key Results
- Studied the electrical properties of different material combinations.
- Observed that conductivity increased with additional Graphene coating layers.
- Found that triple-coated samples prepared at room temperature produced a stronger output than the tested oven-heated samples.
- Evaluated the sensor's response through practical tests.

## 📈 Sensor Characterization
- **Material Analysis:** Compared different material combinations through simulation.
- **Conductivity Testing:** Studied the effect of Graphene coating layers.
- **Performance Testing:** Examined sensor output under loading conditions and after washing.

## 🎯 Key Takeaway
This project provided practical experience in piezoelectric sensor simulation, fabrication, and testing for potential wearable applications.
